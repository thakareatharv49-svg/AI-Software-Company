# M57 — Project Output Manifest

M57 adds a durable output contract between the persistent factory and the future real project runner.

## Output manifest

Each completed factory project can persist a `ProjectOutputManifest` containing:
- mission ID
- logical project ID
- project name
- output status
- output type
- optional repository
- optional GitHub result message
- optional memory ID
- creation and update timestamps

## API

`GET /api/missions/{mission_id}/outputs`

Returns the persisted output manifests for the mission in newest-first order.

## Scope

M57 establishes the durable handoff contract. It does **not** claim that the generic 12-stage factory has become the full M36 artifact-producing runner.

The existing M36 runner still requires its complete request contract plus explicit deployment and monitoring adapters. A later milestone can connect that runner to this manifest without inventing missing inputs or external side effects.

M52 bounded retries, M54 recovery controls, and M55 audit history remain unchanged.
