# M23 — AI Tool-Calling Orchestration

M23 adds a deterministic orchestration layer above the M22 AI tool-calling
contract.

Flow:

AI response
→ M23 orchestration
→ M22 AI tool calling
→ M21 agent boundary
→ M20 tool executor
→ permission policy
→ tool result

The orchestration layer does not bypass M20 permissions and does not introduce
shell, Python execution, arbitrary filesystem access, or arbitrary command
execution.

The first implementation executes tool calls sequentially and preserves the
model response text.
