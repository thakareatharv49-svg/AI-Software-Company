# M25 — AI Tool Execution Audit

M25 adds metadata-only audit events around AI tool execution.

Audit records intentionally avoid storing:

- tool arguments
- tool outputs
- arbitrary model content

They retain only:

- tool name
- result status
- actor
- timestamp
- output/error presence

This preserves the prevention-first boundary and avoids turning the audit
layer into an uncontrolled data store.
