# M31 — AI Execution Coordinator

## Goal

Provide one integration boundary for AI execution.

## Implementation

M31 introduces `AIExecutionCoordinator`.

The coordinator connects:

1. AI execution runtime
2. execution observability
3. persistent execution history

The coordinator executes an AI tool-calling flow, converts the result into an
execution observation, and persists the observation as history.

## Components

- `AIExecutionCoordinator`
- `build_ai_execution_coordinator`
