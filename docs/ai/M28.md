# M28 — AI Execution Runtime

M28 establishes the provider-independent AI execution runtime.

Execution flow:

AI response
→ execution context
→ bounded M27 tool-calling loop
→ M22 AI tool-calling boundary
→ M21 agent tool boundary
→ M20 permission and execution boundary
→ tool result

The runtime provides:

- execution identity
- actor propagation
- bounded tool execution
- bounded orchestration rounds
- safe tool execution through existing permission boundaries
- a provider-independent runtime API

Provider-specific model integrations remain outside this runtime.

The runtime never executes arbitrary Python, shell commands, or filesystem
operations directly.
