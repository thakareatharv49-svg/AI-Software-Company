# M27 — Bounded AI Tool-Calling Loop

M27 adds a bounded loop around the M22 provider-independent tool-calling
contract.

The loop enforces:

- maximum tool-call count
- maximum orchestration rounds
- actor propagation
- sequential tool execution

The loop never executes arbitrary shell commands, Python code, or filesystem
operations. All tool execution remains behind M20 permissions and M21/M22
boundaries.
