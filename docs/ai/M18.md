# M18 — Real AI Model Layer

## Goal

Introduce a provider-independent AI model abstraction that allows the autonomous company to execute real AI inference without coupling the runtime to a specific provider.

## Components

- `AIRequest` — normalized model request.
- `AIResponse` — normalized model response.
- `AIModel` — provider-independent model contract.
- `AIModelRegistry` — model registration and resolution.
- `DeterministicAIModel` — deterministic implementation for tests.

## Design Rules

1. Runtime code must depend on the `AIModel` contract, not a provider SDK.
2. Provider integrations must implement the same interface.
3. Model selection must be registry-driven.
4. Tests must remain deterministic and must not require paid APIs.
5. API keys and provider credentials must never be stored in source code.
6. M18 first establishes the abstraction; real provider adapters are added after the contract is stable.
