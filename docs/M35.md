# M35 — Continuous Learning Engine

## Goal

Turn company experience into inspectable improvement signals.

## Implementation

- Success and failure analysis.
- Agent performance evaluation.
- Strategy recommendations.
- Duplicate-free knowledge consolidation.

## Company Integration

`CompanyOperations.learn()` reads the persistent M31 execution history produced by the AI execution coordinator and feeds those real execution records into M35.

Learning is deliberately bounded: recommendations are produced for review and do not silently rewrite prompts, tools, or autonomy policy.
