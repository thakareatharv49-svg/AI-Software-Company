# M58 — Output Observability

M58 makes M57 project output manifests visible to human operators.

## Control center

The `/app` dashboard now includes a Project outputs panel. Selecting a mission loads its persisted output manifests.

Displayed fields include project name, output status, output type, and repository when available.

## Scope

M58 is an observability milestone. It does not claim that the generic factory is already producing external repositories, deployments, or production services.

Those fields become populated when a future milestone connects the real artifact-producing runner.
