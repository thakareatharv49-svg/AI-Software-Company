# M33 — Multi-Agent Collaboration

## Goal

Enable specialized agents to operate as one engineering organization.

## Implementation

- `CollaborationMessage` — structured communication.
- `Handoff` — explicit task transfer with context.
- `CollaborationBus` — deterministic routing and synchronization.
- `DependencyCoordinator` — dependency-aware readiness.

## Company Integration

`CompanyOperations.handoff_research()` converts an M32 research report into an explicit researcher-to-engineer handoff containing the query, source IDs, evidence, and confidence.

This makes collaboration part of the execution path instead of a standalone data structure.
