# M54 — Mission Recovery & Operator Controls

M54 makes the M53 mission lifecycle operationally recoverable without introducing unbounded autonomous execution.

## Operator controls

### Cancel
POST /api/missions/{mission_id}/cancel

A queued mission can be cancelled. Cancelled jobs are terminal and cannot be accidentally requeued.

### Retry
POST /api/missions/{mission_id}/retry

Failed or blocked missions can be manually returned to the factory queue. The existing M52 retry limits still apply to automatic retries.

## Restart recovery

When the control center starts, persisted jobs in running state are explicitly recovered to queued.

Recovery preserves mission and plan data, preserves the attempt counter, records a recovery message and timestamp, and does not automatically execute the recovered job.

## Safety

M54 does not add infinite retries, automatic process-start execution, time-based background compute, or silent bypasses of terminal lifecycle states.

The factory remains sequential and bounded by M52 controls.
