# M20 — Universal Tool System

## Goal

Create a provider-independent tool execution layer for future AI models and
agents.

## Components

- ToolDefinition
- ToolRequest
- ToolResult
- ToolRegistry
- ToolPermissionPolicy
- ToolPermissionEngine
- ToolExecutor
- deterministic `echo` tool
- deterministic `add` tool

## Security

Default execution permits only `READ` risk tools.

Supported risk levels:

- READ
- WRITE
- EXECUTE
- EXTERNAL

Unknown tools are rejected.

Denied tools never execute.

Arguments are validated before execution.

Tool failures become structured `ToolResult` objects.

## Prevention First

M20 intentionally does not provide:

- arbitrary shell execution
- arbitrary code execution
- unrestricted filesystem access
- unrestricted network access
- provider-specific model dependencies

Higher-risk capabilities will require explicit security boundaries in later
milestones.

## Future

The system will later support:

- AI model tool calling
- agent tool selection
- sandbox tools
- filesystem tools
- GitHub tools
- browser tools
- project-generation tools
- audit logging
