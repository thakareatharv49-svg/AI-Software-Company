# M66–M70 Company Intelligence

## M66 — Cross-Project Memory
A reusable memory index stores project insights and supports recall, search, and project history. The execution pipeline records successful project outcomes.

## M67 — Continuous Learning
LearningEngine records structured execution signals, computes success rates and averages, and emits reusable lessons.

## M68 — Autonomous Decision Engine
DecisionEngine ranks options using expected value, confidence, risk, and cost, producing a deterministic decision and rationale.

## M69 — Cost & Resource Management
CostController enforces hard cost, token, and runtime budgets and exposes remaining capacity.

## M70 — Company Portfolio Management
PortfolioManager scores, ranks, and selects projects according to expected value, confidence, risk, and cost.

These services are intentionally deterministic and composable so later autonomous discovery and company-loop milestones can build on them without replacing the existing execution architecture.
