# M52 — Autonomous Factory Scheduler

M52 adds bounded scheduling controls to the persistent M51 project factory.

## Controls

- Only one factory run may be active at a time.
- Failed projects can be retried up to a caller-selected retry limit.
- Retry attempts are persisted.
- Interrupted projects remain recoverable through the M51 queue restoration path.
- Factory status exposes whether a run is active and how many projects are queued.
- The factory endpoint accepts `max_retries=0..5`.

## Safety

Retries are bounded. A project that continues failing becomes blocked rather than looping forever. The scheduler remains sequential: one project at a time.

## Boundary

M52 does not introduce unconstrained autonomous compute or background execution after process restart. Restart recovery remains explicit, and model workloads remain bounded by factory controls.
