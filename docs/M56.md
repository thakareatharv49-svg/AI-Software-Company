# M56 — Audit Operator View

M56 turns the M55 audit trail into an operator-facing inspection surface.

## API

GET /api/missions/{mission_id}/audit

Optional query filters: event_type for an exact lifecycle event type, and status for an exact mission status. Results remain chronological.

## Control center

The /app dashboard now includes a Mission audit panel. Selecting a mission displays its durable lifecycle history, including the lifecycle event, resulting status, message, and timestamp.

## Scope

M56 is an observability/operator milestone. It does not add new autonomous execution behavior, retries, deployment side effects, or background compute.

Existing M52 retry bounds, M54 recovery controls, and M55 append-only audit semantics remain unchanged.
