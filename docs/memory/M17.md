# M17 — Memory Integration

M17 connects the persistent memory layer to autonomous company execution.

## Integrated flows

Mission / Task / Decision
        ↓
Persistent Memory
        ↓
Context Retrieval
        ↓
Autonomous Execution
        ↓
Success / Failure
        ↓
Execution Memory
        ↓
Future Context

## Memory captured during execution

- execution started
- execution completed
- execution failure
- project association
- run association
- agent association
- retrieved context

## Company-level memory capabilities

The integration layer also supports:

- mission memory
- task memory
- decision memory
- failure memory
- agent handoff memory
- execution memory

## Restart protection

Memory is persisted to disk and can be loaded by a new runtime instance.

This means an execution can finish, the process can stop, and a later runtime instance can retrieve the previous execution context.

## Scope

M17 intentionally keeps the JSON persistence backend.

Production PostgreSQL + semantic/hybrid retrieval belongs to M26.
