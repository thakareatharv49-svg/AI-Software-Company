# M32 — Real-World Research Engine

## Goal

Provide a provider-independent research boundary that produces validated,
source-backed research reports.

## Components

- ResearchSource
- ResearchFinding
- ResearchReport
- ResearchProvider
- StaticResearchProvider
- ResearchEngine

## Design

The core engine is deterministic and provider-independent. A real web,
documentation, market, or technology research adapter can implement
ResearchProvider without changing the report model.

Research output always retains source identity, evidence, and confidence.

## Safety

The engine does not treat an arbitrary answer as authoritative. Sources are
explicit objects and duplicate source identities are rejected during source
validation.

## Validation

M32 requires unit tests for source-backed findings, query validation,
case-insensitive retrieval, and duplicate-source validation.
