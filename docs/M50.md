# M50 — Autonomous Project Factory

## Goal

Turn the M49 continuous mission runner into a sequential project factory: queue projects, complete one project, then automatically start the next queued project.

## Lifecycle

1. Queue one or more CompanyMission objects.
2. Build each mission's deterministic 12-stage plan without starting execution.
3. Start the first queued project.
4. Run its planned stages through the existing M49/M48 execution pipeline.
5. When all stages complete, finalize the project and start the next queued project.
6. If a project blocks, stop the factory and leave remaining projects queued.
7. max_projects and max_stages provide bounded execution controls.

## Safety

The factory does not bypass the existing agent executor, runtime, permissions, stop control, or failure handling. A blocked project prevents later queued projects from running.

## M49 repair

M50 also restores the success path in MissionExecutionPipeline.execute_next() that was accidentally placed after the M49 loop during the previous change. This ensures a successful stage returns its AgentResult, advances the plan, and can trigger project completion.

## Boundary

M50 provides the company-level project queue and sequential lifecycle. It does not claim that every planned specialist stage has real-world integrations behind it; those capabilities remain governed by their existing milestones and adapters.
