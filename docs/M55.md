# M55 — Mission Audit History

M55 adds a durable, append-only audit trail for mission lifecycle activity.

## Audit records

Each record contains an audit id, mission id, event type, human-readable message, resulting lifecycle status when available, timestamp, and structured metadata.

## Recorded activity

The audit trail records mission creation, queueing, factory execution attempts, completion, retry/requeue, pause, blocking, and cancellation.

## API

GET /api/missions/{mission_id}/audit

The endpoint returns audit entries in chronological order and returns 404 for an unknown mission.

## Persistence

Audit entries are stored in the `mission_audit` table through Alembic migration `m55_mission_audit`.

The audit trail is append-only from the application API: entries are never updated as lifecycle state changes.

## Safety

M55 is observational. It does not add autonomous execution, retries, or external side effects. Existing M52-M54 bounds and operator controls remain unchanged.
