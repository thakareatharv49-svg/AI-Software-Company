# M49 — Autonomous Stage Loop

## Goal

Remove the manual one-stage-at-a-time boundary from M48 by allowing the company to continuously execute planned mission stages until completion, failure, or an explicit stage limit.

## Flow

1. M47 creates the 12-stage mission plan.
2. M48 maps each stage to an agent and executes one stage.
3. M49 repeatedly invokes M48 for the next planned stage.
4. Success advances automatically to the next stage.
5. Failure blocks the company and stops the loop.
6. A completed project stops the mission loop cleanly.
7. max_stages provides a deterministic safety boundary for tests and controlled runs.

## API

- POST /api/missions/{mission_id}/execute — execute one stage.
- POST /api/missions/{mission_id}/execute-all — continuously execute stages.
- Optional max_stages=1..12 limits one autonomous run.

## Safety

The loop does not bypass the existing agent executor, permissions, runtime, stop control, or failure handling. It stops when the company is no longer running, an agent fails, or the configured stage limit is reached.

## Boundary

M49 establishes continuous stage execution. It does not claim that downstream GitHub, deployment, monitoring, or learning integrations are fully operational merely because those stages exist in the plan.
