# M59 — Real M36 Runner Integration

M59 connects the persistent project factory to the existing M36 `AutonomousProjectRunner` through an explicit adapter.

## Architecture

- `FactoryAutonomousRunner` accepts an M36 runner and a request builder.
- `ProjectFactory` uses the adapter when configured; the existing M48–M49 pipeline remains the fallback.
- A successful M36 result marks the factory plan complete.
- M57 output manifests are enriched with the real project id, repository, GitHub message, and memory id when the M36 runner supplies them.

## Safety

The factory does not invent research, deployment, GitHub, or monitoring adapters. Those dependencies remain explicit inputs to `AutonomousProjectRunner` and its `AutonomousProjectRequest`.

Therefore enabling the adapter is opt-in and testable; the default control center behavior remains unchanged until a real request builder and M36 runner are injected.

## Scope

M59 establishes the real integration boundary. It does not claim that the default web application can autonomously create arbitrary production repositories without configured external adapters.
