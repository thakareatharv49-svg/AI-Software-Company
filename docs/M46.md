# M46 — Company Web Application & Productization

## Status

IMPLEMENTED / VALIDATION PENDING

## Delivered

- FastAPI control-center API for company state and mission submission.
- Mission history backed by the application control plane.
- Human stop control exposed through the backend.
- Existing dashboard summary and event APIs surfaced in the application.
- Responsive dark control-center web UI at /app.
- Polling-based live state/event refresh without a second runtime.
- Integration tests for mission submission, running-mission protection, UI/API wiring and stop control.

## Boundary

M46 productizes the existing company engine. It intentionally does not claim M47 one-mission autonomy: the current M36 orchestration contract still owns downstream execution inputs. M46 provides the user-facing control surface that M47 will connect to the higher-level mission controller.

## Acceptance path

1. Open /app.
2. Submit one mission name and objective.
3. The backend records the mission and starts the company orchestrator.
4. The UI displays company state, mission history and company events.
5. The operator can invoke the stop control.

## Next

M47 will replace the current externally prepared M36 execution contract with a mission-only controller that derives research, product, architecture, tasks, agents, QA, security, GitHub, deployment, monitoring and learning inputs internally.
