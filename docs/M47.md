# M47 — Mission Controller

## Goal

M47 turns the control-center's human input into an internal company plan.

The operator supplies only:

- mission name
- mission objective
- optional constraints

The controller derives the internal lifecycle:

1. Research
2. Product
3. Architecture
4. Tasks
5. Agents
6. Execution
7. QA
8. Security
9. GitHub
10. Deployment
11. Monitoring
12. Learning

## Architecture

`CompanyControlCenter` remains the application boundary.

`MissionController` is the mission-level planning layer.

`CompanyOrchestrator` remains the state-transition authority.

M47 creates the project/task handoff and records the first executable stage. It does **not** claim that all twelve stages are already implemented or that an LLM agent has completed engineering work. Those execution capabilities are integrated in later milestones.

## Acceptance

A submitted mission must:

- start the company;
- create a deterministic internal mission plan;
- select a mission-scoped project;
- select the first research task;
- emit planning and pipeline-ready events;
- preserve the existing stop/block controls.

## Next

The next milestone connects planned stages to agent execution and stage transitions so the company can advance through the generated pipeline autonomously.
